How to Run the Generator

To use this generator on your Windows machine:

  • Open the solution in Visual Studio: AcmeApp/AcmeApp.sln
  • Build the project (Ctrl+Shift+B)
  • Run the application (F5)
  • Click "Spiritual Template Generator" button
  • Configure your template settings
  • Export as SVG and import to Canva or print directly
