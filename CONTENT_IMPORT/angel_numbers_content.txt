ИНСТРУКЦИЯ: Как добавить свой контент
===========================================

1. Откройте этот файл Блокнотом (Notepad)
2. Скопируйте структуру ниже для каждого Angel Number
3. Вставьте СВОЙ текст вместо [ваш текст здесь]
4. Сохраните файл (Ctrl+S)
5. Запустите программу - она автоматически прочитает этот файл!
