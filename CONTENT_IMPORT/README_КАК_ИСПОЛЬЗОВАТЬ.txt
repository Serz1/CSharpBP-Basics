===========================================
ШАГ 1: Найдите эту папку
===========================================

Путь к папке:
/home/user/CSharpBP-Basics/CONTENT_IMPORT/

Как найти:
1. Откройте "Проводник" (File Explorer)
2. Перейдите в папку "user"
3. Затем "CSharpBP-Basics"
4. Затем "CONTENT_IMPORT"

ИЛИ просто введите в адресной строке:
/home/user/CSharpBP-Basics/CONTENT_IMPORT/

===========================================
ШАГ 2: Откройте файлы Блокнотом
===========================================

Вы увидите 3 файла:

📄 angel_numbers_content.txt
   - Для контента Angel Numbers (111-999)

📄 planner_months_content.txt
   - Для тем и вопросов планнера

📄 content_rules.txt
   - Для ваших правил создания контента

Откройте любой из них:
- Правой кнопкой мыши → Открыть с помощью → Блокнот

===========================================
ШАГ 3: Вставьте свой контент
===========================================

1. Скопируйте ваш текст из Word/Google Docs/где угодно
2. Вставьте в нужное место в файле (Ctrl+V)
3. Следуйте формату который показан в файле
4. Сохраните (Ctrl+S)

ВАЖНО:
- Не удаляйте [NUMBER:111] и [END] - это разделители!
- Сохраняйте формат: "ИмяПоля: Значение"
- Можно писать длинные тексты - переносы строк ОК

===========================================
ШАГ 4: Запустите программу
===========================================

1. Откройте Visual Studio
2. Откройте проект Acme.sln
3. Нажмите F5
4. Программа АВТОМАТИЧЕСКИ прочитает ваши файлы!
5. Экспортируйте - получите шаблоны с ВАШИМ контентом!

===========================================
❓ ЧАСТЫЕ ВОПРОСЫ
===========================================

Q: Где искать эту папку?
A: /home/user/CSharpBP-Basics/CONTENT_IMPORT/

Q: Каким редактором открывать?
A: Блокнот (Notepad), или любой текстовый редактор

Q: Можно ли редактировать в Word?
A: Да, но сохраняйте как .txt, не .docx!

Q: Что если я ошибся в формате?
A: Программа покажет ошибку. Проверьте что:
   - Есть [NUMBER:111] в начале
   - Есть [END] в конце
   - Есть двоеточия после названий полей

Q: Обязательно заполнять ВСЕ поля?
A: Нет! Можно оставить пустыми, но двоеточие оставьте:
   FrequencyNote:
   (пустое значение - ОК)

Q: Как добавить больше Angel Numbers?
A: Скопируйте секцию от [NUMBER:777] до [END]
   Измените номер на нужный (например 1010)
   Заполните контент
