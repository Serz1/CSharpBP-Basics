# 🚀 Как запустить генератор шаблонов AISoulGuide

## Для непрограммистов - Простая инструкция

### Что вам нужно:

1. **Visual Studio** (бесплатная Community версия подойдёт)
   - Скачать: https://visualstudio.microsoft.com/ru/downloads/
   - Выбрать: Visual Studio Community (бесплатная)
   - При установке выбрать: "Разработка классических приложений .NET"

---

## 📝 Пошаговая инструкция запуска:

### Шаг 1: Открыть проект

1. Запустите Visual Studio
2. Нажмите **"Открыть проект или решение"**
3. Перейдите в папку: `CSharpBP-Basics/AcmeApp/`
4. Выберите файл: **`Acme.sln`** (файл с иконкой Visual Studio)
5. Нажмите **"Открыть"**

### Шаг 2: Запустить программу

**Вариант А (самый простой):**
- Нажмите клавишу **F5** на клавиатуре

**Вариант Б:**
- Нажмите зелёную кнопку ▶️ **"Запуск"** (Start) вверху окна
- Или в меню: **Отладка → Начать отладку**

### Шаг 3: Использовать программу

После запуска откроется окно с кнопками:

1. **"Template Generator"** - Нажмите эту кнопку
2. Откроется генератор шаблонов со следующими настройками:

   **Слева - Панель настроек:**
   - **Page Format** - Выберите формат страницы (US Letter, A4, Card Standard и т.д.)
   - **Color Scheme** - Выберите цветовую схему (Shadow Awakening, Luminous Harmony)
   - **Template Type** - Выберите тип шаблона:
     - Background - Фоновый шаблон
     - CardFront - Передняя сторона карточки
     - CardBack - Задняя сторона карточки
     - BookSpread - Разворот книги (2 страницы)
   - **Angel Number** - Выберите номер ангела (111, 222, 777)
   - **Sacred Geometry** - Выберите сакральную геометрию

   **Справа - Предпросмотр:**
   - Здесь вы увидите готовый SVG код
   - Нажмите **"Generate Preview"** чтобы обновить
   - Нажмите **"Export SVG"** чтобы сохранить файл

---

## 💾 Как сохранить готовый шаблон:

1. Настройте все параметры слева
2. Нажмите **"Generate Preview"**
3. Нажмите **"Export SVG"**
4. Выберите папку для сохранения
5. Введите имя файла (например: `angel-card-111-front.svg`)
6. Нажмите **"Сохранить"**

## 🎯 Использование SVG файлов:

После экспорта вы можете:

1. **Загрузить в Canva**
   - Elements → Uploads → Upload File
   - Выберите ваш .svg файл

2. **Редактировать в Inkscape** (бесплатно)
   - Скачать: https://inkscape.org/ru/
   - Открыть SVG файл
   - Редактировать как векторную графику

3. **Печатать**
   - SVG формат бесконечно масштабируется
   - Подходит для любого размера печати

## ❓ Если что-то не работает:

### Ошибка при запуске:
1. Убедитесь что установлен **.NET Framework 4.6** или выше
2. В Visual Studio: **Сборка → Пересобрать решение**
3. Попробуйте снова нажать F5

### Программа открывается, но ничего не генерируется:
1. Проверьте что выбраны все настройки
2. Нажмите кнопку **"Generate Preview"**
3. Если не помогает - перезапустите программу

### SVG файл не открывается:
1. Попробуйте открыть в браузере (Chrome, Firefox)
2. Или в Inkscape
3. Убедитесь что файл сохранился с расширением `.svg`

## 🔧 Дополнительные возможности:

### Изменить цвета:
- Файл: `Models/ColorScheme.cs`
- Найдите вашу схему (Shadow Awakening / Luminous Harmony)
- Измените hex коды цветов (например: `#FFD700`)

### Добавить новые Angel Numbers:
- Файл: `Models/TemplateTypes.cs`
- Найдите метод `GetPredefinedAngelNumbers()`
- Добавьте новый `AngelNumberContent` по примеру существующих

### Изменить размеры шрифтов:
- Файлы: `Services/BrandedCardGenerator.cs` и `Services/SpecializedTemplateGenerator.cs`
- Найдите `font-size="XX"` и измените число
- Сейчас все шрифты уменьшены на 25% от оригинала
