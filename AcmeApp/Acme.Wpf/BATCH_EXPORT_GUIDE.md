# 📦 Руководство по Массовому Экспорту

## Что это?

Функция **Batch Export** (массовый экспорт) позволяет вам одним кликом экспортировать **ВСЕ** шаблоны для вашего продукта.

---

## 🎯 Что будет экспортировано?

### ✅ Полный экспорт (Export All):

Нажав одну кнопку, вы получите:

- **18 файлов Angel Cards** (9 номеров × передняя + задняя сторона)
- **9 файлов Book Spreads** (разворот книги для каждого номера)
- **2 файла Quick Guide** (передняя + задняя карточка)
- **12 файлов Planner Months** (все месяцы года)
- **20 файлов Journal Pages** (образцы страниц журнала)
- **5 файлов Backgrounds** (фоны с разной геометрией)

**ИТОГО: 66+ готовых файлов!** 🎉

## 🚀 Как использовать

### Вариант 1: Экспорт ВСЕГО

1. Откройте программу
2. Выберите **Color Scheme** (Shadow Awakening или Luminous Harmony)
3. Нажмите кнопку **"Export All Collection"**
4. Выберите папку для сохранения
5. Подождите 5-10 секунд
6. Получите уведомление с отчётом!

### Вариант 2: Экспорт только Angel Cards

1. Выберите Color Scheme
2. Нажмите **"Export Angel Cards Only"**
3. Выберите папку
4. Готово! (~29 файлов)

### Вариант 3: Экспорт только Planner

1. Выберите Color Scheme
2. Нажмите **"Export Planner Only"**
3. Выберите папку
4. Готово! (~32 файла: месяцы + журнальные страницы)

## 💡 Советы по использованию

### Для массовой загрузки в Canva:

1. Экспортируйте все файлы
2. В Canva: **Elements → Uploads → Upload files**
3. Выберите ВСЕ файлы из нужной папки
4. Canva загрузит их все сразу
5. Используйте в своих дизайнах!

### Для печати:

- SVG формат идеален для печати
- Бесконечная масштабируемость
- Откройте в Inkscape или Adobe Illustrator
- Экспортируйте в PDF для печати

### Для продажи на Etsy/Gumroad:

1. Экспортируйте коллекцию
2. Создайте ZIP архив каждой папки
3. Загрузите как Digital Download
4. Продавайте!

## ⚙️ Настройки экспорта

### Какие параметры влияют на экспорт?

- **Color Scheme** - цветовая схема для ВСЕХ файлов
  - Shadow Awakening: тёмная, мистическая
  - Luminous Harmony: светлая, воздушная

### Можно ли изменить количество файлов?

Да! В коде (`BatchExportService.cs`):

```csharp
// Изменить количество журнальных страниц
ExportSampleJournalPages(folder, scheme, 20); // 20 → любое число

// Добавить больше фонов
// Добавьте геометрию в массив geometryTypes
```

- Файлы сохраняются в выбранную вами папку

- Имена файлов стандартизированы для удобства

## ❓ Часто задаваемые вопросы

**Q: Сколько времени занимает экспорт?**
A: 5-15 секунд для полной коллекции (66 файлов)

**Q: Можно ли экспортировать в другие форматы?**
A: Сейчас только SVG. Для PNG/PDF используйте Inkscape для конвертации

**Q: Можно ли изменить цвета после экспорта?**
A: Да! SVG файлы можно редактировать в любом векторном редакторе

**Q: Что если мне нужны только определённые номера?**
A: Экспортируйте всё, затем удалите ненужные файлы

**Q: Файлы перезаписываются?**
A: Да, если вы экспортируете в ту же папку повторно
